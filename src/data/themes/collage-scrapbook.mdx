Collage design combines paper surfaces, image cutouts, and graphic accents in several visible layers. It works well when the content already includes photography, art, or event material. Layering should retain a clear reading order.

## When to Use

This style suits entertainment websites, brand campaigns, and creative portfolios. Avoid it for long forms and data-heavy interfaces where overlapping decoration obscures controls.

## Key Visual Elements

Use a limited set of paper textures and accent colors. Keep the main heading and call to action unobstructed. Decorative rotation and overlap should reduce on mobile. Use real content images with useful descriptions instead of filling every gap with a sticker.

## Typography

Anton gives short headlines a condensed shape. DM Sans supports longer descriptions and controls. Use a limited number of text sizes so layered panels remain easy to scan.
