Risograph / Print simulates two ink layers, an offset between them, and fine grain. The preview applies this treatment to a grayscale illustration so the change is visible. This filter is a visual approximation of print, not a print-production separation tool.

## Image Treatment

The filter uses red and blue ink mappings, a three-unit SVG offset, and static grain. Export the SVG filter definition and add it once to the target page. Apply `filter: var(--tx-media-filter)` to selected images or illustrations. CSS variables alone do not contain the filter definition. JSON export includes both its settings and SVG markup.

## Layout and Interaction

Use a simple layout around image blocks. Keep text and controls unfiltered. Preserve original images when their colors have a practical meaning. Avoid animated grain and moving ink offsets.

## Combining Themes

Select this theme as a visual effect layer to preserve the base typography and layout while adding print surfaces and image treatment. A color mode changes interface colors while the two image ink colors remain fixed.
