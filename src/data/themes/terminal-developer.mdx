Terminal design uses monospace type, aligned panels, and command examples to make technical content easy to scan. It is useful for developer products and portfolios that include actual code. Navigation should remain understandable without requiring command-line knowledge.

## When to Use

This style suits developer products, technical portfolios, and SaaS documentation. Avoid it for consumer checkout flows where terminal conventions need extra explanation.

## Key Visual Elements

Use code examples as content rather than decoration. Label actions and states in plain words. Avoid flashing cursors, automatic typing over important text, and color-only status messages. Give long code blocks their own horizontal scrolling area.

## Typography

Space Mono provides distinct headings. IBM Plex Mono gives code, tables, and descriptions a consistent character width. Keep the body font large enough for sustained reading.
