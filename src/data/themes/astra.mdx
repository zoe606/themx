Astra is a space-themed style for dashboards and developer tools. A single orbital diagram establishes the visual identity. The rest of the page uses readable, opaque panels and clear controls.

## Layout

Place the orbital diagram beside a left-aligned heading. Give the main data panel more width than supporting panels. Use a compact navigation row or sidebar when the content needs it. Stack panels on phones and keep the reading order unchanged.

## Color and type

Use cyan for primary actions and lavender for secondary elements. Reserve amber for attention states. Include text with status colors. Use Space Grotesk for headings and IBM Plex Sans for labels, forms, and tables.

## Motion

Orbital motion is optional. Animate only the decorative diagram. Keep text and controls stationary. Respect reduced motion and provide a static diagram when animation is disabled.
