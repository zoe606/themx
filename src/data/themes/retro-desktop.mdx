Retro Desktop uses the window surfaces, borders, and controls associated with classic desktop interfaces. It suits portfolios, small developer tools, and interactive projects where the visual reference supports the content.

## Key Visual Elements

Use gray panels, navy title bars, square corners, and contrasting bevels. Inputs should look inset. Label navigation and actions clearly. Window decorations should not imply unsupported dragging, closing, or resizing.

## Layout and Interaction

Keep windows in the normal document flow. Stack them on small screens instead of overlapping them. Use real buttons, readable text, and visible keyboard focus. A pressed button should have an inset border, while its selected state remains clear after focus moves.

## Typography

IBM Plex Sans keeps small labels and longer descriptions readable. Use bold text for title bars and panel headings. Keep bitmap lettering limited to optional decorative labels.
