Editorial layouts organize articles, images, and captions with a clear reading order. Serif headings and thin rules distinguish sections without adding heavy containers. The design should work with real article lengths, rather than only short placeholder headings.

## When to Use

This style suits publications, ecommerce features, and creative portfolios. Avoid it for dense operational dashboards that need compact controls.

## Key Visual Elements

Keep body text around 60 to 75 characters per line. Use a consistent type scale for the headline, summary, body, and caption. Reserve multi-column layouts for summaries and collapse them on small screens. Include useful image descriptions and visible links.

## Typography

Libre Baskerville provides distinct serif headings. Source Sans 3 keeps body copy and navigation readable. Use serif type for emphasis and a consistent body font for long passages.
