Duotone converts an image to grayscale and maps its shadows and highlights to two colors. The preview shows the original illustration beside a violet-and-yellow version. The treatment changes image colors, not just the surrounding interface palette.

## Image Treatment

The first ink defines shadows and the second defines highlights. Intermediate tones interpolate between them. Export the SVG filter definition and add it once to the target page. Apply `filter: var(--tx-media-filter)` only to images and illustrations. JSON export includes the ink settings and the same SVG definition.

## Layout and Interaction

Use the treatment consistently across selected image blocks. Keep text, controls, and informative charts unfiltered. Retain original colors when they matter for product choice or understanding instructions. Duotone has no grain or registration offset.

## Combining Themes

Select Duotone as a visual effect layer to retain the base typography and layout. Color modes change interface colors while retaining the selected image ink mapping.
